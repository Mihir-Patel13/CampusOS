# CampusOS
🎓 CampusOS — Your Student Command Center

CampusOS is an all-in-one student productivity platform designed to help students manage academic deadlines, assignments, courses, and milestones from a single, clean dashboard.

---

## 💡 The Problem
University students routinely juggle multiple disconnected tools for assignments, syllabi, and notes. This causes cognitive overload, missed deadlines, and academic stress. CampusOS unifies academic tracking into one private, browser-based command center.

---

## 🚀 Key Features
- **Student Authentication:** Password-protected local accounts with fully isolated data per student.
- **Custom Course Support:** Easily add and manage custom subjects and electives for any semester.
- **Smart Priority Triage:** Rule-based deadline prioritization:
  - 🔴 **HIGH Priority:** Due within 48 hours
  - 🟡 **MEDIUM Priority:** Due within 3 days
  - 🔵 **LOW Priority:** Due after 3 days
- **Celebrations & Milestones:** Track exams, personal milestones, and project submissions with celebratory canvas confetti.
- **Notes Hub:** Quick lecture notes with instant search.
- **Theme Support:** Modern SaaS dark/light mode with full mobile responsiveness.

---

## 🛠️ Built With
- **HTML5 & CSS3** (Vanilla, responsive layout)
- **JavaScript (ES6)** (Modular logic, CustomEvents)
- **Browser LocalStorage** (Fast, offline-first persistence)
- **Font Awesome & Google Fonts**
